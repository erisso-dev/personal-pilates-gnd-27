# Personal Pilates Gandía · propuesta de web 2027

Rediseño de la home de personalpilatesgandia.com. Página estática, sin compilación.

- `web/index.html`: la página. Ábrela en el navegador.
- `web/assets/`: logotipo, fotos reales de la web actual y, en `generadas/`, tres imágenes hechas con IA (prompts en `prompts.md`).
- `logo/`: logotipo vectorizado (calco del PNG original de 300 px) en versión normal y para fondo oscuro.
- `web/vista-previa.png`: captura completa a 1440 px.

Pendiente: probar en móvil real, conectar el formulario a un servidor y sustituir las imágenes generadas por fotos del estudio.
